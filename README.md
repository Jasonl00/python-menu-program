# python-menu-program
Create a menu program that lets users add, remove, find the maximum and minimum values, and sort the list in the descending order. 
## Features

- Add values
- Remove values
- Display maximum and minimum values
- Sort values in descending order

## Skills Demonstrated

- User input
- Conditional logic
- Loops
- Working with collections
- Sorting and data manipulation

## Purpose

This project was created as part of my programming coursework
to practice working with collections and program control flow.

## How to Run

1. Download or clone the repository.
2. Open the project in the appropriate development environment.
3. Run the main program file.
